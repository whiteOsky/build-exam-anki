## 导入

1. 下载需要的 `.apkg`，或下载完整合集后解压。
2. 在 Anki 中点击“导入文件”。
3. 卡片会以全新状态进入对应学科和章节子牌组。

每个附件均保留卡片内容、字段、模板、标签和章节层级，但不包含原账户的复习记录、到期时间、学习队列、遗忘次数、flags 或个人牌组选项。完整机器可读统计和校验值见 [manifest.json](manifest.json)。

英语牌组包含明确标识的第三方词汇内容，因缺少公开再分发授权而未上传。
